# 💰 Controle de Gastos

Aplicação simples para gerenciar despesas pessoais: adicione, visualize e remova gastos, com cálculo automático do total.

## 📚 Sobre o projeto

Projeto desenvolvido para praticar conceitos de JavaScript, como manipulação de DOM, eventos, formatação de valores monetários e delegação de eventos.

## ✨ Funcionalidades

- Adicionar despesas com nome, categoria e valor
- Formatação automática do valor em Real (BRL) durante a digitação
- Remoção de itens da lista com atualização instantânea do total
- Contagem dinâmica da quantidade de despesas
- Cálculo automático do total gasto

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

## 🧠 Conceitos aplicados

- Manipulação de DOM
- Delegação de eventos
- Formatação de moeda com `Intl` / `toLocaleString`
- Tratamento de erros com `try/catch`
